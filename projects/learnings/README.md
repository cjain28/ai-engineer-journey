# 📚 Learnings

Day-by-day Python practice while moving from JavaScript to Python for AI work.

## 🗓️ Topics
| Files | Topic |
|-------|-------|
| `hello.py`, `basics.py`, `day2.py` | Variables, data types, functions, if/else, for and while loops |
| `day3.py`, `day3_mini.py`, `list_Comprehension.py` | Default arguments, list comprehensions |
| `day4.py`, `day4_challenge.py`, `errorHandling.py` | Nested dictionaries, `.get()`, try/except |
| `multiple.py`, `job_calculator.py` | Returning multiple values, loops with calculations |
| `day5.py`, `day5_challenge.py` | First HTTP requests with `requests` |
| `day6.py`, `day6_challenge.py` | Classes, objects, inheritance and `super()` |
| `day7.py` | First LLM API call with the Groq API |
| `rag_intro.py`, `ilPython.py`, `smart_chunk.py` | First steps into RAG: chunking and keyword retrieval |

## ▶️ How to run
```bash
python day6.py
```
Files that call the Groq API (`day7.py`, `rag_intro.py`) need `GROQ_API_KEY` in a `.env` file.

The numbers used in these exercises are sample data.
